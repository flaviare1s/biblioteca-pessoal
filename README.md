## 📋 Sobre o Projeto

Este é um projeto de biblioteca pessoal desenvolvido com React e Firebase, onde você pode cadastrar livros, adicionar categorias e informar se o livro já foi lido ou não. Foi elaborado em grupo por **Flávia Reis**, **Arthur Cavalcante** e **Moisés Almeida** como uma das avaliações do bootcamp da SoulCode Academy.

### 🎯 Objetivo

Criar um CRUD completo utilizando React e Firebase para gerenciar um catálogo de livros, apresentando as quatro operações básicas: criação, leitura, atualização e exclusão de dados.

---

## 🚀 Tecnologias Utilizadas

- ⚛️ **React** - Biblioteca JavaScript para construção de interfaces
- 🔥 **Firebase** - Backend as a Service (Authentication e Firestore)
- 🎨 **Bootstrap** - Framework CSS para estilização
- ⚡ **Vite** - Build tool e dev server

---

## ✨ Funcionalidades

### Funcionalidades Principais

- ➕ **Inserção de Dados**: Formulário com validação para adicionar novos livros
- 📖 **Listagem de Dados**: Exibição dos livros cadastrados em formato visual organizado
- ❌ **Remoção de Dados**: Função de exclusão com confirmação do usuário
- ✏️ **Atualização de Dados**: Formulário com validação para editar as informações dos livros
- 🔐 **Autenticação de Usuário**: Páginas de cadastro e login para autenticação dos usuários

### Funcionalidades Extras

- ✉️ **Envio de Email de Verificação**: Confirmação de email para novos usuários
- 🔍 **Filtros de Busca**: Filtros básicos para facilitar a localização de livros na listagem
- 🔑 **Recuperação de Senha**: Sistema de redefinição de senha por email

## 💻 Instalação e Execução

### Pré-requisitos

- Node.js (versão 14 ou superior)
- npm ou yarn

### Passos para Instalação

1. Clone o repositório:

```bash
git clone https://github.com/Linsarthur/biblioteca-pessoal
cd biblioteca-pessoal
```

2. Instale as dependências:

```bash
npm install
```

3. Inicie o servidor de desenvolvimento:

```bash
npm run dev
```

4. Abra o navegador e acesse `http://localhost:5173`
