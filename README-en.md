## 📋 About the Project

This is a personal library project developed with React and Firebase, where you can register books, add categories, and track whether the book has been read or not. It was developed as a group project by **Flávia Reis**, **Arthur Cavalcante**, and **Moisés Almeida** as part of an assessment for the SoulCode Academy bootcamp.

### 🎯 Objective

Create a complete CRUD application using React and Firebase to manage a book catalog, featuring the four basic operations: create, read, update, and delete data.

---

## 🚀 Technologies Used

- ⚛️ **React** - JavaScript library for building user interfaces
- 🔥 **Firebase** - Backend as a Service (Authentication and Firestore)
- 🎨 **Bootstrap** - CSS framework for styling
- ⚡ **Vite** - Build tool and dev server

---

## ✨ Features

### Main Features

- ➕ **Data Insertion**: Validated form to add new books
- 📖 **Data Listing**: Display of registered books in an organized visual format
- ❌ **Data Removal**: Delete function with user confirmation
- ✏️ **Data Update**: Validated form to edit book information
- 🔐 **User Authentication**: Registration and login pages for user authentication

### Extra Features

- ✉️ **Verification Email**: Email confirmation for new users
- 🔍 **Search Filters**: Basic filters to facilitate book search in the listing
- 🔑 **Password Recovery**: Email-based password reset system

## 💻 Installation and Setup

### Prerequisites

- Node.js (version 14 or higher)
- npm or yarn

### Installation Steps

1. Clone the repository:

```bash
git clone https://github.com/Linsarthur/biblioteca-pessoal
cd biblioteca-pessoal
```

2. Install dependencies:

```bash
npm install
```

3. Start the development server:

```bash
npm run dev
```

4. Open your browser and navigate to `http://localhost:5173`

---

## 📦 Available Scripts
